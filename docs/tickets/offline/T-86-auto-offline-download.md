# T-86: automatic offline download of a trail's map

Owner idea, three parts:

- a setting that downloads a trail's offline map automatically when its GPX is imported;
- on an opened trail, a big button under the description to download its map offline ("I'll do
  it, download offline");
- a map downloaded automatically is deleted after a month; one downloaded by hand is kept.
